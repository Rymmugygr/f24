# f24

## Тестовое задание

Получение курсов, кроскурсов ЦБ.

## Требования:

- на входе: дата, код валюты, код базовой валюты (по-умолчанию RUR);
получать курсы с http://cbr.ru;
- на выходе: значение курса и разница с предыдущим торговым днем;
- кешировать данные http://cbr.ru.
- продемонстрировать навыки работы с брокерами сообщений и реализовать сбор данных с cbr за 180 предыдущих дней с помощью воркера через консольную команду.

*Note*: в требованиях указано использование **RUR** как базовой валюты по-умолчанию. Этот код валюты относится к рублю до деноминации 1998, поэтому я бы рекомендовал использовать код **RUB** при выполнении запросов к api, во избежание недоразумений. Сделано допущение, что курс обмена RUR -\> RUB за всю историю неизменен и составляет 1 000 -\> 1. Дополнительно это привело к ограничению на запрос курсов датой начиная с 1998-01-02 включительно. 
## Быстрый старт

Необходимы установленные [Docker](https://www.docker.com/) и [docker-compose](https://docs.docker.com/compose/)

_Note_: разработка велась с использованием [OrbStack](https://orbstack.dev/) и рекомендуется использовать его же, во
избежания проблем с именем хоста (что бы доступ к _localhost_ работал из коробки)

**Все указанные ниже команды следует выполнять из корневой директории проекта**

Запуск приложения
```bash

```

При первом запуске может потребоваться установка зависимостей вручную

|---|---|

### Контейнеры docker-compose

| Сервис | Назначение |
|---|---|
| `gateway` | Nginx, порт 80 |
| `backend` | PHP-FPM с приложением |
| `worker` | Консьюмер очереди `currency_daily` |
| `broker` | RabbitMQ |
| `redis` | Redis (без персистентности) |

Конфигурация DEV окружения лежит в `build/dev/*`.

## Консольные команды

Запускаются внутри контейнера `backend`:

```bash
docker-compose -f build/dev/docker-compose.yml -p f24 run --rm backend bin/console <команда>
```

| Команда | Описание |
|---|---|
| `app:currency:daily [YYYY-MM-DD]` | Загрузить курсы из ЦБ за дату (по умолчанию — сегодня) |
| `app:currency:last` | Поставить в очередь загрузку курсов за последние 180 дней |
| `app:currency:worker` | Обрабатывать очередь `currency_daily` (запущен в контейнере `worker`) |

*Note*: Приложение использует Symfony 7.4 https://symfony.com/, также приложению доступны и его команды.

## Конфигурация

Основные переменные окружения (`.env`):

| Переменная | Значение по умолчанию |
|---|---|
| `REDIS_URL` | `redis://:pass@redis:6379` |
| `MESSENGER_TRANSPORT_DSN` | `amqp://user:pass@broker:5672/%2f/messages` |

Исходный код приложения добавляется в контейнер `backend` через монтирование директории, поэтому его изменения "видны" контейнеру сразу.

Но при изменении исходного кода будет необходим перезапуск воркера очередей (контейнер `worker`), ибо для уже запущенной команды изменения не "видны".
